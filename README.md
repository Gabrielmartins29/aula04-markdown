## Comandos básicos

O comando `git status` mostra o estado dos arquivos.

O comando `git add README.md` prepara o arquivo para o commit.

O comando `git commit` registra uma versão local.

O comando `git push` envia os commits para o GitHub.

Exemplo de sequência:

```bash
git status
git add README.md
git commit -m "Adiciona README da aula"
git push -u origin main
```
